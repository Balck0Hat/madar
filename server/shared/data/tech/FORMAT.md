# صيغة موضوعات خريطة التقنية — `tech/topics/<branch>.js`

كل ملف يصدّر مصفوفة موضوعات فرع واحد بحسب `tree.js` (المعرّفات فيه ملزمة وترتيبها ملزم). كل موضوع **سطر واحد** (الملف ≤ 150 سطراً). العربية فصيحة سهلة للقارئ العام، والمصطلحات الإنجليزية تُذكر بين قوسين عند أول ورود. علامات الاقتباس المزدوجة لسلاسل JS فقط؛ داخل النص ' أو «».

```js
export default [
  { id: "dns", title: "نظام أسماء النطاقات", en: "DNS", level: "intermediate",
    summary: "دليل الهاتف للإنترنت: يحوّل الاسم الذي تكتبه (google.com) إلى عنوان رقمي يفهمه الحاسوب.",
    how: ["حين تكتب عنواناً، يسأل جهازك خادم DNS: ما عنوان IP لهذا الاسم؟", "الجواب يُحفظ مؤقتاً (cache) في جهازك وفي الراوتر فلا يُسأل في كل مرة.", "الأسماء مرتّبة هرمياً: com ثم google ثم www.", "إن تعطّل DNS يبدو الإنترنت معطلاً مع أن الاتصال سليم."],
    uses: ["تغيير DNS إلى 1.1.1.1 أو 8.8.8.8 قد يسرّع التصفح أو يتجاوز حجباً.", "رقابة الأهل على الأجهزة تعمل غالباً عبر DNS."],
    terms: [{ en: "IP address", ar: "عنوان IP", note: "العنوان الرقمي للجهاز على الشبكة." }, { en: "cache", ar: "ذاكرة مؤقتة", note: "نسخة محفوظة لتسريع الطلب التالي." }],
    myths: [{ wrong: "DNS هو الشركة التي تبيعني الإنترنت.", right: "DNS خدمة دليل فقط، وقد تكون من غير مزوّد الإنترنت.", note: "المزوّد يعطيك الاتصال، وDNS يترجم الأسماء." }],
    related: ["ip-addresses", "http-https"] },
];
```

| الحقل | القاعدة |
|---|---|
| `level` | basics (المستخدم العادي: ما هو وكيف يستعمله) · intermediate (كيف يعمل من الداخل ومتى يختار ماذا) · advanced (تفاصيل تقنية ومقارنات للمهتم) |
| `summary` | جملة أو جملتان: تعريف بلغة بسيطة مع تشبيه من الحياة إن أمكن |
| `how` | 3–5 نقاط: كيف يعمل، خطوة خطوة أو فكرة فكرة |
| `uses` | 2–4 نقاط: أين يقابله القارئ في حياته، وقرارات عملية (ماذا يختار، ماذا يفعل) |
| `terms` | 2–5 مصطلحات `{ en, ar, note }` يسمعها القارئ في هذا الموضوع، بالإنجليزية والعربية وشرح قصير |
| `myths` | 2–3 مفاهيم خاطئة شائعة `{ wrong, right, note }`: ما يظنه الناس، الصواب، ولماذا |
| `related` | 1–3 معرّفات موضوعات من الشجرة (يجوز من فروع أخرى) |

الدقة أولاً: أرقام ومعايير حالية (2026)، بلا ماركات مفضّلة، وبلا نصائح خطرة. لا تنسخ من مواقع؛ الصياغة أصلية.
