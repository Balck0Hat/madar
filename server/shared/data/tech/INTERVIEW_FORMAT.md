# صيغة أسئلة المقابلة — `tech/interview/<branch>.js`

كل ملف يصدّر كائناً مفاتيحه معرّفات موضوعات الفرع (من `tree.js`) وقيمه مصفوفة أسئلة. لكل موضوع 4–6 أسئلة، **كل سؤال سطر واحد**، الملف ≤ 150 سطراً. العربية فصيحة سهلة؛ المصطلحات الإنجليزية بين قوسين عند أول ورود. علامات الاقتباس المزدوجة لسلاسل JS فقط.

```js
export default {
  "dns": [
    { q: "ما هو DNS ولماذا نحتاجه؟", level: "basics", a: "دليل يحوّل الاسم المقروء (google.com) إلى عنوان IP رقمي يفهمه الحاسوب؛ بدونه نحفظ أرقاماً بدل الأسماء.", hint: "شبّهه بدليل الهاتف." },
    { q: "ماذا يحدث خطوة خطوة حين أكتب عنواناً في المتصفح؟", level: "intermediate", a: "يبحث الجهاز في ذاكرته المؤقتة، ثم يسأل الراوتر، ثم خادم DNS المزوّد، الذي يسأل الخوادم الجذرية ثم خوادم النطاق حتى يصل للعنوان، ويُحفظ الجواب مؤقتاً.", hint: "الترتيب والذاكرة المؤقتة هما بيت القصيد." },
    { q: "لماذا قد يبدو الإنترنت معطلاً مع أن الاتصال سليم؟", level: "intermediate", a: "لأن DNS معطل أو بطيء فلا تُترجم الأسماء؛ الاختبار: فتح موقع بعنوان IP مباشرة ينجح.", hint: "فرّق بين الاتصال والترجمة." },
    { q: "ما الفرق بين DNS over HTTPS والـ DNS التقليدي؟", level: "advanced", a: "التقليدي يرسل الاستعلام مكشوفاً فيراه المزوّد أو أي متنصّت؛ DoH يشفّره داخل HTTPS فيحمي الخصوصية ويصعّب الحجب.", hint: "الخصوصية والتشفير." },
  ],
};
```

| الحقل | القاعدة |
|---|---|
| `q` | سؤال كما يطرحه مُقابِل حقيقي (وظيفة، امتحان شفهي، نقاش)، واضح وقصير |
| `level` | basics · intermediate · advanced؛ لكل موضوع سؤال أساسي واحد على الأقل وسؤال متقدم واحد على الأقل |
| `a` | الإجابة النموذجية في 1–3 جمل: مباشرة، صحيحة، تُظهر الفهم لا الحفظ |
| `hint` | تلميح قصير (اختياري) يساعد المجيب قبل كشف الجواب |

الأسئلة أصلية ومتّسقة مع محتوى الموضوع في `topics/<branch>.js` (لا تناقضه). لا أسئلة تتطلب حفظ أرقام دقيقة تتغير كل سنة.
