# دليل محتوى قسم الإنجليزية — اختبار تحديد المستوى

الأسئلة بالإنجليزية، والشروح (`why`) بالعربية الفصيحة السهلة. كل الأسئلة **أصلية**: لا تنسخ من امتحانات رسمية أو كتب. المستويات: A1, A2, B1, B2, C1 بمعيار CEFR.
كل ملف ≤ 150 سطراً (كل سؤال أو مقطع على سطر واحد). علامات الاقتباس المزدوجة لسلاسل JS فقط؛ داخل النص استعمل ' أو «».

## placement/grammar.js — قواعد ومفردات
```js
export default [
  { id: "g-a1-01", level: "A1", skill: "grammar", q: "She ___ to school every day.", opts: ["go", "goes", "going", "went"], a: 1, why: "المضارع البسيط مع she يأخذ -s: goes." },
  { id: "g-b2-07", level: "B2", skill: "vocab", q: "The committee reached a ___ after hours of debate.", opts: ["consensus", "consent", "coincidence", "conscience"], a: 0, why: "consensus = إجماع؛ consent = موافقة؛ الخياران الآخران بعيدان معنىً." },
];
```
25 سؤالاً لكل مستوى (125 مجموعاً)، نصفها grammar ونصفها vocab تقريباً. كل سؤال 4 خيارات، خيار واحد صحيح بلا لبس، والخيارات الخاطئة معقولة (أخطاء يقع فيها العرب: a/the، الأزمنة، حروف الجر، الكلمات المتشابهة). `a` فهرس الخيار الصحيح (يبدأ من 0)، وزّع الفهرس الصحيح بين 0 و3 بالتساوي تقريباً. المستوى يجب أن يكون حقيقياً: A1 جمل من 6 كلمات ومفردات يومية؛ C1 تراكيب مركّبة (inversion, mixed conditionals, hedging) ومفردات أكاديمية.

## placement/reading.js — قراءة
```js
export default [
  { id: "r-b1-1", level: "B1", title: "A new bicycle lane", text: "…150–260 words…", qs: [ { q: "…", opts: ["…","…","…","…"], a: 2, why: "…بالعربية…" } ] },
];
```
5 مقاطع: A2، B1، B2، B2، C1. المقطع بمستوى مفرداته وجمله (A2: جمل قصيرة، موضوع يومي؛ C1: نص أكاديمي/رأي فيه حجج مجرّدة). 5 أسئلة لكل مقطع بأنواع الآيلتس: تفصيل، فكرة رئيسة، معنى كلمة من السياق، استنتاج، صح/خطأ/غير مذكور (اجعله خيارات: True / False / Not given / …).

## placement/listening.js — استماع (يقرؤه المتصفح بصوته)
```js
export default [
  { id: "l-b1-1", level: "B1", kind: "dialogue", lines: [ { who: "Woman", text: "…" }, { who: "Man", text: "…" } ], qs: [ { q: "…", opts: ["…","…","…","…"], a: 1, why: "…" } ] },
];
```
5 نصوص: A2 (حوار قصير)، B1 (حوار)، B2 (حوار)، B2 (محاضرة قصيرة monologue واحد `who: "Speaker"`)، C1 (محاضرة). 120–200 كلمة لكل نص، 4 أسئلة لكل نص. النص يُقرأ صوتياً فاجعله طبيعياً منطوقاً (اختصارات، تكرار خفيف) وتجنب الأسماء العسيرة النطق.
