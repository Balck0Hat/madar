# دليل محتوى قسم الإنجليزية — اختبار تحديد المستوى

الأسئلة بالإنجليزية، والشروح (`why`) بالعربية الفصيحة السهلة. كل الأسئلة **أصلية**: لا تنسخ من امتحانات رسمية أو كتب. المستويات: A1, A2, B1, B2, C1 بمعيار CEFR.
كل ملف ≤ 150 سطراً (كل سؤال أو مقطع على سطر واحد). علامات الاقتباس المزدوجة لسلاسل JS فقط؛ داخل النص استعمل ' أو «».

## placement/grammar/<level>.js — قواعد ومفردات (ملف لكل مستوى)
```js
export default [
  { id: "g-a1-01", level: "A1", skill: "grammar", tag: "be-have", q: "She ___ to school every day.", opts: ["go", "goes", "going", "went"], a: 1, why: "المضارع البسيط مع she يأخذ -s: goes." },
  { id: "g-b2-07", level: "B2", skill: "vocab", tag: "academic-vocab", q: "The committee reached a ___ after hours of debate.", opts: ["consensus", "consent", "coincidence", "conscience"], a: 0, why: "consensus = إجماع؛ consent = موافقة." },
];
```
50 سؤالاً لكل مستوى (250 مجموعاً)، نصفها grammar ونصفها vocab تقريباً. `tag` من `tags.js` (موضوع السؤال؛ منه يُحسب تقرير الضعف وخطة الأسبوعين). كل سؤال 4 خيارات، خيار واحد صحيح بلا لبس، والخيارات الخاطئة معقولة (أخطاء يقع فيها العرب). `a` فهرس الخيار الصحيح، وزّعه بين 0 و3 بالتساوي تقريباً. المستوى يجب أن يكون حقيقياً: A1 جمل من 6 كلمات ومفردات يومية؛ C1 تراكيب مركّبة ومفردات أكاديمية.

**المعايرة:** مستوى السؤال المكتوب هنا هو نقطة البداية فقط. الخادم يسجّل لكل سؤال كم مرة سُئل وأُجيب صحيحاً (`ItemStat`)، وكل ليلة (3:30) يرفع درجة كل سؤال أصاب فيه أقل من 35% بعد 30 إجابة، ويُنزل ما أصاب فيه أكثر من 90%. المستوى المعاير يُستعمل في السلّم بدل المكتوب. لا تعدّل `level` يدوياً بسبب البيانات؛ دع المعايرة تعمل.

## placement/reading.js — قراءة
```js
export default [
  { id: "r-b1-1", level: "B1", title: "A new bicycle lane", text: "…150–300 words…", qs: [
    { k: "detail", q: "…", opts: ["…","…","…","…"], a: 2, why: "…" },
    { k: "tfng", type: "tfng", q: "The lane opens in May.", opts: ["True", "False", "Not given"], a: 2, why: "…" },
    { k: "gap", type: "gap", q: "Work on the lane took ___ months.", answers: ["six", "6"], why: "…" },
  ] },
];
```
8 مقاطع (A2×2، B1×2، B2×2، C1×2). 6 أسئلة لكل مقطع بهذا الترتيب: detail، main (أو purpose)، vocab، inference (أو attitude)، tfng، gap. `k` نوع السؤال (من `QKINDS` في tags.js) ويُستعمل في التقرير. `type: "tfng"` بثلاثة خيارات ثابتة؛ «Not given» يعني أن النص لا يقول شيئاً في الأمر فعلاً. `type: "gap"` بلا خيارات: يكتب المتعلم كلمة واحدة أو رقماً من النص، و`answers` كل الصيغ المقبولة بحروف صغيرة (الكلمة والرقم)، والجملة تُعيد صياغة النص فلا يكفي البحث الحرفي.

## placement/listening.js — استماع (ملفات صوتية حقيقية)
```js
export default [
  { id: "l-b1-1", level: "B1", accent: "us", kind: "dialogue", lines: [ { who: "Woman", text: "…" }, { who: "Man", text: "…" } ], qs: [ { k: "detail", q: "…", opts: ["…","…","…","…"], a: 1, why: "…" } ] },
];
```
8 نصوص (A2×2، B1×2، B2×2، C1×2)، 120–210 كلمة، 4 أسئلة لكل نص بـ`k` (detail, main, inference, attitude, purpose). `accent` gb أو us، و`who` حصراً Man / Woman / Speaker (الأصوات تُختار بها). النص يُقرأ بمحرك صوتي فاجعله منطوقاً: اختصارات، الأرقام والأوقات بالحروف (nine thirty)، بلا أقواس ولا رموز ولا أسماء عسيرة.

**توليد الصوت:** بعد أي إضافة أو تعديل شغّل من `server/`: `node scripts/english-audio.js` (يولّد ما لا ملف له) أو `--force` أو بأرقام النصوص. يستعمل edge-tts (أصوات عصبية بريطانية وأمريكية، بلا مفتاح) وffmpeg، ويكتب `client/public/audio/english/<id>.mp3`. الملفات تُرفع مع الكود. إن تعذّر تحميل الملف عند المستخدم يقرأ المتصفح النص بصوته.

## سير الاختبار (للمرجع)
القواعد: تبدأ من B1، إجابتان صحيحتان تصعد، خطأ ينزل؛ تتوقف بين 12 و24 سؤالاً حين تستقر آخر ستة أسئلة بين مستويين متجاورين. الثقة: عالية إن أصاب مستواه ≥70% وأخفق فيما فوقه ≤35%، منخفضة إن لم يستقر. القراءة والاستماع: مقطع بالمستوى ومقطع أعلى، من غير ما رآه سابقاً. مؤقّتات: قواعد 12 دقيقة، قراءة 14، استماع 10 (تُحفظ في الخادم). النتيجة: وسيط الأجزاء، والكتابة تُزيح درجة على الأكثر.
