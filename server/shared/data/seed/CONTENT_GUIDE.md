# دليل كتابة وحدة في مدار

ملف واحد لكل وحدة: `server/shared/data/seed/units/<unitId>.js` يصدّر `export default { ... }`.
المعرّف: `<domain>-1-<n>` (مثل `earth-1-4`) أو `center-<n>`. العنوان يُؤخذ تلقائياً من `shared/data/tree.js` — اكتبه كما هو هناك.
المرجع الكامل بالمستوى المطلوب: `units/human-1-3.js` (النوم). التحقق: `node scripts/validate-seed.js <unitId>` من مجلد `server/`.

## الشكل

```js
export default {
  unitId: "earth-1-4",
  title: "الطقس: لماذا تمطر وتهب الرياح",          // كما في tree.js
  hero: { num: "40%", label: "من أشعة الشمس تعكسها السحب" }, // رقم لافت وصحيح + وصفه
  spark: "...",        // 60–110 كلمة: سؤال أو حقيقة مدهشة تفتح الوحدة
  goals: ["...", "...", "...", "..."],           // 3–4 أهداف تبدأ بفعل: تصف، تفسّر، تميّز، تطبّق
  cards: [ { h: "عنوان", p: "80–120 كلمة", art: "brain" }, ... ], // 8–10 بطاقات، كل واحدة فكرة واحدة
  tryIt: { title: "...", text: "..." },          // تمرين تطبيقي يفعله القارئ الآن (40–80 كلمة)
  deep: { title: "كتاب/محاضرة/فيلم وثائقي حقيقي", why: "لماذا اخترناه، بصدق وبأي تحفظ" },
  thread: { to: "life-1-5", text: "...", q: "...", opts: ["...", "...", "...", "..."], a: 1, why: "..." }, // وحدة في مجال آخر بالمدار الأول
  summary: ["...", "...", "...", "...", "..."], // 4–5 جمل تلخّص الوحدة
  questions: [ /* 24–30 سؤالاً، انظر أدناه */ ],
};
```

## البطاقات
- تسلسل قصصي: من السؤال المدهش إلى الآلية إلى ما يعنيه للقارئ في حياته. كل بطاقة تحمل فكرة واحدة وعنواناً من 2–5 كلمات.
- رقم أو مثال ملموس أو تجربة تاريخية في معظم البطاقات. لا عموميات.
- لغة عربية فصيحة سهلة، جمل قصيرة، بلا حشو ولا مقدمات. المصطلح الأجنبي بين قوسين عند أول ذكر فقط.
- **الدقة أهم من الإبهار**: لا تذكر رقماً أو تاريخاً أو اسماً لست متأكداً منه؛ استعمل «نحو» و«قرابة» للتقديرات، ولا تختلق دراسات. في الموضوعات الخلافية (تاريخ، دين، سياسة) اعرض الروايات بحياد واذكر أن الخلاف قائم.
- `art` واحد من: `wheel brain eye cycle wash transfer shield bed drop sunmoon list curve bars network` — اختر الأقرب معنىً.

## بنك الأسئلة (24–30)
- الأنواع: `mcq` (10 على الأقل، 4 خيارات، `a` مؤشر الصحيح من 0)، `tf` (4–6، `a` صح/خطأ)، `fill` (2–4، `a` مصفوفة إجابات مقبولة قصيرة بصيغ متعددة)، `order` (1–2، `items` 3–4 عناصر و`a` مصفوفة الترتيب الصحيح بمؤشرات من 0)، `open` (1–3، مع `keywords` من 4–8 كلمات/جذور تدل على الإجابة الصحيحة).
- كل سؤال له `qid` فريد (`q1`…`q30`) و`why` من جملة واحدة تشرح الجواب (تُعرض بعد الإجابة).
- غطِّ كل البطاقات؛ اجعل ثلث الأسئلة تطبيقية (موقف من الحياة) لا حفظاً. الخيارات الخاطئة معقولة لا سخيفة، ومتقاربة الطول. لا «كل ما سبق».
- التقاط الأسئلة عشوائي (10 من البنك) فلا تعتمد أسئلة على بعضها.

## الخيط
سؤال واحد يربط الوحدة بوحدة في **مجال آخر** من المدار الأول (انظر `tree.js` للمعرّفات). الأزواج المعتمدة إن انطبقت: human-1-3↔tech-1-7، history-1-7↔tech-1-6، earth-1-5↔life-1-5، society-1-2↔tools-1-2، matter-1-7↔earth-1-1، arts-1-3↔history-1-4، religion-1-6↔arts-1-2، life-1-7↔human-1-1، center-1↔tools-1-8.

# المدار الثاني والثالث

المعرّف `<domain>-2-<n>` أو `<domain>-3-<n>`. القارئ هنا أنهى المدار الأول كله، فلا تُعِد شرح الأساسيات — ابنِ عليها.

| | المدار الأول | **الثاني** | **الثالث** |
|---|---|---|---|
| الزمن | 40 د | **60 د** | **90 د** |
| البطاقات | 8–10 | **11–13** | **13–16** |
| الأسئلة | 24–30 | **30–34** | **32–38** |
| كلمات البطاقة | 80–120 | **100–140** | **110–150** |

**الفرق الحقيقي ليس الطول بل العمق:**
- **المدار الأول** يجيب «ما هذا؟» — الظاهرة وآليتها ومعناها لحياتك.
- **المدار الثاني** يجيب «كيف نعرف ذلك، وما تفاصيله؟» — الآلية بدقة، التجربة التي أثبتتها، الأرقام، الاستثناءات، والخلاف القائم بين الباحثين.
- **المدار الثالث** يجيب «أين حدود معرفتنا؟» — النظرية بصيغتها الناضجة، المدارس المتنافسة، الأسئلة المفتوحة، وما زال مجهولاً. يُسمح هنا بمصطلح تقني بشرط تعريفه، وبمعادلة واحدة بشرط شرح معناها لا اشتقاقها.

**قواعد إضافية للمدارين:**
- اذكر **أسماء الباحثين وسنوات الدراسات** التي بُنيت عليها المعرفة، لا النتيجة وحدها.
- خصّص بطاقة واحدة على الأقل لـ**ما هو متنازع عليه أو مجهول** في الموضوع.
- الأسئلة أصعب: ثلثها على الأقل تطبيقي أو تحليلي (سيناريو، تفسير نتيجة، اكتشاف مغالطة) لا استرجاعاً.
- الخيط يشير إلى وحدة في **مجال آخر** من أي مدار (الأول أو الثاني أو الثالث).
- `deep` هنا يمكن أن يكون كتاباً متخصصاً أو محاضرة جامعية أو ورقة مرجعية، لا كتاب تبسيط فقط.
- كل خيارات سؤال الاختيار **متقاربة في الطول** — لا تجعل الإجابة الصحيحة أطول من البقية، فذلك يكشفها.
