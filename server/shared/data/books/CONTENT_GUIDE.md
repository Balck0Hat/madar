# دليل محتوى قسم الكتب

كل كتاب مجلد فيه `book.js` (بيانات الكتاب) وفصول `NN-slug.js`. الملفات ≤ 150 سطراً (النصوص الطويلة على سطر واحد).

## الصوت والأسلوب (إلزامي)
- عربية فصيحة سهلة، مخاطبة القارئ بـ«أنت»، جمل قصيرة، لا حشو ولا مواعظ.
- كل فكرة تُنسب إلى صاحبها حين تكون لغيرنا (ديفيد آلن، كال نيوبورت، جيمس كلير، تياغو فورتي، غريغ ماكيون، أوليفر بيركمان، بارابانتوفيتش الخ). لا تخترع دراسات أو أرقاماً؛ إن ذكرت رقماً فمن مصدر معروف أو اكتبه تقريباً.
- كل فصل فيه: قصة أو مثال ملموس من حياة يومية عربية (موظف، طالب، أم، صاحب متجر)، ثم الفكرة، ثم **تمرين واحد** يُنفَّذ اليوم في أقل من 20 دقيقة، ثم **ثلاث خلاصات**.
- لا كلام عام مثل «كن منظماً». كل نصيحة لها خطوات وأرقام وأمثلة.
- الكتاب الثاني ساخر في عنوانه («مبالغ فيه») فاجعل صوته أخفّ وأجرأ، لكن محتواه جادّ ومجرّب.

## `book.js`
```js
export default {
  bookId: "do-everything",
  order: 1,
  title: "افعل كل شيء",
  subtitle: "كيف تجد وقتاً لكل شيء",
  tagline: "جملة واحدة تقول ما سيتغير في حياة القارئ بعد الكتاب (20-30 كلمة).",
  cover: { color: "#C9A227", glyph: "⏳" },   // لون الكتاب ورمز إيموجي واحد
  audience: "لمن هذا الكتاب، جملة.",
  promise: "ما الذي ستخرج به، 3 نقاط في جملة واحدة.",
  intro: "مقدمة الكتاب 250-350 كلمة: المشكلة، لماذا فشلت الحلول المعتادة، ماذا يختلف هنا، كيف تقرأه.",
  sources: ["الكتب والمراجع التي بُني عليها، 5-8 عناوين بأصحابها"],
};
```

## فصل `NN-slug.js`
```js
export default {
  chapterId: "why-time-vanishes",
  order: 1,
  title: "عنوان الفصل",
  hook: "افتتاحية 60-90 كلمة: مشهد ملموس يعرّف القارئ نفسه فيه.",
  sections: [               // 4 إلى 6 أقسام، كل قسم 150-260 كلمة، بعناوين قصيرة ذات معنى (لا «مقدمة»)
    { h: "…", p: "…" },
  ],
  exercise: { title: "تمرين اليوم", steps: ["خطوة 1", "خطوة 2", "خطوة 3"], minutes: 15 },
  takeaways: ["خلاصة 1", "خلاصة 2", "خلاصة 3"],
  check: { q: "سؤال اختيار من متعدد من الفصل", opts: ["..", "..", "..", ".."], a: 1, why: "شرح في جملة." },
};
```
طول الفصل الكلي 1000-1500 كلمة. علامات الاقتباس «». الأرقام غربية. لا علامة اقتباس مزدوجة داخل النصوص.
